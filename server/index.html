Messages on the web

It’s in the server’s log (Portainer: the container’s Logs; Docker: docker compose logs fluidmessages) and in its data folder as setup-code. It stops working once you’ve made a password, so nobody else can claim this server.

At least 8 characters. A few words together is easy to remember and hard to guess.

Forgot your password?

On the server, run docker compose exec fluidmessages python main.py reset-password. It signs out every browser and prints a new setup code, so you can choose a new password. Your messages and accounts stay. If your server has a FLUID_TOKEN, you can also sign in with it and change the password in Settings.
