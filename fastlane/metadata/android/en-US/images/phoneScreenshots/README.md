# Phone screenshots

There are no screenshots from a real phone yet, so this folder has none on purpose. Please don't add mockups or images made on a computer.

To add them, take screenshots on a phone in the **sample inbox** (Settings → Help → Sample inbox), which uses only made-up names and messages. Save them here as `1.png`, `2.png`, and so on, in the order they should show. Check that no real names, numbers, messages, or link codes are in any of them.
